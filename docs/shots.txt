# Screenshot recipes: name | keys, sent to a fresh launch of riff on the fixture PR
# (see docs/screenshots.md). Keys are tmux send-keys tokens: a letter, a string, Enter,
# Escape, Space, C-p …; `wait` pauses for a background load; `type:"text"` types text.
# riff opens PR mode on the overview; `d` switches to the diff.

# ── PR ────────────────────────────────────────────────────────────────────────
overview         |
checks           | k l
diff             | d
tree             | d C-b

# ── Reading ───────────────────────────────────────────────────────────────────
hunks            | d ] c ] c ] c
folds            | d z M
flash            | d s l i m i t
search           | d / r e t r y Enter n
commit           | d ] g
commit-picker    | d C-p type:"select commit" Enter

# ── Comments ──────────────────────────────────────────────────────────────────
thread           | d ] r Enter
outdated         | d ] r ] r Enter
compose          | d ] c ] c j j c type:"Does this keep the abort signal while queued?"
visual           | d ] c ] c V j j j
comments-picker  | d g C
review-preview   | d ] c ] c j j c type:"Does this keep the abort signal while queued?" Enter Escape g S
sync-preview     | d ] r Enter r type:"Forwarding the signal now." Enter Escape g s

# ── Everything else ───────────────────────────────────────────────────────────
action-menu      | d C-p
file-picker      | d C-f
help             | d g ?
